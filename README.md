# 图片信息查看与简单编辑工具（img_tool）

## 1. 项目介绍

这是一个 **命令行** Python 程序，用于：

- 读取图片基础信息：文件名、格式、宽高、颜色模式、文件大小；
- 对图片做简单编辑：缩放、裁剪、旋转、翻转、灰度化、格式转换。

所有编辑结果都保存为新文件，**不会覆盖原图**，运行结束会打印保存位置。

支持的功能：

| 功能 | 命令 |
| --- | --- |
| 读取信息 | `info` |
| 缩放 | `resize` |
| 裁剪 | `crop` |
| 旋转 | `rotate` |
| 翻转 | `flip` |
| 灰度化 | `grayscale` |
| 格式转换 | `convert` |
